# Эмулятор оболочки UNIX (вариант 6)
Эмулятор командной оболочки UNIX-подобной ОС (CLI), реализованный на Kotlin. Выполняется в режиме эмуляции терминала: рабоатет с виртуальной файловой системой (VFS) и поддерживает запуск стартовых скриптов.
## 1. Общее описание
Проект разрабатывается поэтапно. На данный момент реализованы:
- **Этап 1.** Минимальный прототип REPL: интерактивный ввод команд, парсер, команды-загулшки `ls` и `cd`, команда `exit`.
- **Этап 2.** Конфигурация эмулятора через параметры командной строки,
  поддержка стартового скрипта с остановкой на первой ошибке.
## 2. Описание функций и настроек
### Приглашение к вводу
Приглашание имеет вид `<имя VFS>`, например `vfs> `.

### Парсер 
Строка ввода обрезается по краям и делатися по пробелам на команду (первое слово) и аргументы (остальные слова). Пустой ввод игнорируется.

### Команды
`ls [args...]` - Заглушка. Выводит своё имя и аргументы
`cd [args...]` - Заглушка. Выводит своё имя и аргументы
`exit` - Завершает работу эмулятора
При вводе неизвестной команды выводится сообщение `Unknown command: <имя>`.

### Параметры командной строки
- `--vfs <путь>` — путь к физическому расположению VFS (архив). Пока
  только выводится в отладочном сообщении, подключение VFS — на этапе 3.
- `--script <путь>` — путь к стартовому скрипту с командами эмулятора.

### Функции в коде
`findCommand(input: String): Boolean` разбивает строку и выполняет команду. Возвращает `true`, если команда известна, иначче `false`.
`main` реализует цикл REPL до команды `exit`.

### Стартовый скрипт
Если передан `--script`, эмулятор построчно выполняет команды из файла,
имитируя диалог с пользователем: на экран выводится и приглашение с
командой (как будто её ввёл пользователь), и результат её выполнения.

Выполнение скрипта **останавливается на первой ошибке** (неизвестная
команда) или на строке `exit`. Если скрипт завершился с ошибкой или файл
не найден, эмулятор завершает работу с кодом возврата `1` и не переходит
в интерактивный режим. Если скрипт выполнен успешно, эмулятор переходит
в обычный интерактивный режим.

## 3. Сборка и тесты
Требуется установленный компилятор Kotlin (`kotlinc`).

Сборка и запуск вручную:
kotlinc src/Main.kt -include-runtime -d build/emulator.jar
java -jar build/emulator.jar --vfs ./vfs.zip --script tests/ok.txt

Демонстрационный скрипт, собирающий проект и прогоняющий все варианты
параметров командной строки:
./tests/stage2.sh

Тестовые стартовые скрипты эмулятора:
- `tests/ok.txt` — корректный сценарий, доходит до `exit` без ошибок.
- `tests/fail.txt` — сценарий с неизвестной командой, демонстрирует
  остановку выполнения на первой ошибке.

## 4. Примеры
Интерактивный режим:
vfs> ls -l /home
ls -l /home
vfs> foo
Unknown command: foo
vfs> exit

Запуск со скриптом, содержащим ошибку:
$ java -jar build/emulator.jar --script tests/fail.txt
[DEBUG] VFS path: не задан
[DEBUG] Script path: tests/fail.txt
vfs> ls
ls
vfs> cd /home/user
cd /home/user
vfs> ls -la
ls -la
vfs> unknown_command
Unknown command: unknown_command
[ERROR] Invalid command: unknown_command
$ echo $?
1
